E2EE Chat demo

This page runs the protocol of the E2EE Chat desktop app entirely in your browser. Each user's keys are generated here, every message is encrypted and signed before it reaches the server, and the server panel below shows everything the relay would store: ciphertext, wrapped keys and signatures, never plaintext. Nothing leaves this page. It is a simulation of the protocol, not the desktop app itself.
